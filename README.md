## Project Description

ShopEase is a no-code e-commerce website built on Wix, developed as a continuation of our Assignment IV-a Figma UI/UX design. The goal was to transform our original mobile app prototype into a functional web-based online store, applying the same clean, user-friendly design principles — simple navigation, clear product presentation, and an easy checkout experience.

The website allows visitors to browse products across multiple categories (Electronics, Fashion, Shoes, and Beauty), view detailed product information, add items to a shopping cart, and learn more about the business through the About and Contact pages.

## Features Implemented

- **Homepage** – Store branding, welcome message, and an attractive hero layout representing the ShopEase brand
- **Product Page** – 5+ products with images, names, prices, and descriptions across multiple categories
- **About Page** – Business description and mission statement
- **Contact Page** – Email address, phone number, and a contact form
- **Shopping Cart** – Add-to-cart functionality via Wix Stores, allowing users to add and review products before checkout
- **Responsive Design** – Website adapts to both desktop and mobile screens
- **Consistent Branding** – Blue and white color scheme matching the original ShopEase Figma design
